## 🧭 About

Most developer portfolios get skimmed for a few seconds and closed. This landing page walks through a practical, six-step "build order" for putting together a portfolio that recruiters actually read — from picking a stack, to shipping live projects, to writing case studies instead of captions.

The design leans into the topic itself: a **navy blueprint aesthetic** with grid paper backgrounds, dimension lines, monospace annotations, and a construction-tape marquee — built to feel like a technical drawing of the portfolio you're about to build, rather than another generic SaaS page.

## ✨ Features

- 🎨 **Distinctive blueprint UI** — grid-paper background, corner crop-marks, dimension-line hero diagram
- 🧱 **Six-step build sequence** — a real, ordered process instead of decorative numbering
- 📱 **Fully responsive** — collapses to a clean mobile nav and single-column layout below 700px
- 🖱️ **Every link is live** — course pages, bootcamp page, and blog posts are all clickable, in-page and in the footer
- 🎞️ **One deliberate motion moment** — a scrolling caution-tape marquee band, with `prefers-reduced-motion` respected
- ⚡ **Zero dependencies** — a single self-contained `index.html`, ready for GitHub Pages

## 🚀 Getting started

Clone the repo and open the file directly — no build step required:

```bash
git clone https://github.com/your-username/portfolio-blueprint-landing.git
cd portfolio-blueprint-landing
open index.html   # or just double-click it
```

### Deploy on GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
4. Choose the `main` branch and `/root` folder, then save.
5. Your page will be live at `https://your-username.github.io/portfolio-blueprint-landing/`.
